# Hôte Windows natif

Le binaire Tauri 2 (`Overtype.exe`) conserve les données sensibles côté Rust. Le WebView ne reçoit la clé d’API que dans les fenêtres des Réglages et de l’accueil ; elle est chiffrée par DPAPI avant écriture. Les textes d’historique sont regroupés dans une charge JSON chiffrée par DPAPI dans SQLite. Les métadonnées (date, langue, mode) restent lisibles afin d’appliquer la rétention de sept jours et cent entrées. L’historique est désactivé par défaut.

## Capture et remplacement

`capture_text` interroge le contrôle focalisé avec UI Automation `TextPattern`. Il garde l’identité du contrôle, la plage de sélection, son texte et la fenêtre de premier plan. Le dernier rectangle visible de la plage sert d’ancre physique ; tous les rectangles, regroupés par ligne, forment `selectionRects` (lot 5, docs/BRIDGE.md), sur lesquels la fenêtre `halo` balaie pendant le travail sous l’Îlot (lot 6). Une sélection lisible sans rectangle reste une capture de sélection et s’ouvre en bas de l’écran, sans effet sur le texte ; elle n’est jamais remplacée par le contenu du presse-papiers. Depuis le 15 septembre 2026 (0.4.0) `canReplace` est décidé à la capture, sans second temps : vrai quand UIA a donné la sélection d’un contrôle modifiable (`capture::replaceable`), ou quand la copie synthétique a réussi (une sélection existait donc) ; faux pour une copie faite par l’utilisateur (`fresh`, aucune sélection garantie), un rejeu, une démo, une console (`ConsoleWindowClass`, `CASCADIA_HOSTING_WINDOW_CLASS` : Ctrl+V n’y remplace pas une sélection) et un champ mot de passe. La cible retenue (`TargetIdentity`) se réduit à la fenêtre source, au contrôle focalisé (`GetGUIThreadInfo`), à l’identifiant UIA quand il existe, au texte sélectionné et à son ancre. Si UIA ne fournit aucun texte, Rust copie lui-même : il attend le relâchement de la corde du raccourci (≤ 600 ms), envoie Ctrl+Insert par `SendInput` (la corde de copie CUA, jamais SIGINT dans un terminal ; Insert en scan code étendu, sinon Chromium lit le 0 du pavé numérique), attend ≤ 350 ms que `GetClipboardSequenceNumber` change, attend que ce numéro se stabilise, puis lit le texte et remet l’instantané de tous les formats dans la même session du presse-papiers, de sorte que rien ne s’intercale (`clipboard_guard::take_copy`, 0.6) ; une copie qui arrive après l’attente est encore annulée tant que la session n’a vu aucune saisie (`watch_late`). Sans copie obtenue, une copie faite par l’utilisateur moins de 3 s avant le raccourci (datée par le surveillant toutes les 35 ms, nos propres écritures exclues) est traduite ; sinon la capture échoue par un avis discret, jamais par une boîte de dialogue. `Capture.origin` (`uia`, `copy`, `fresh`, `replay`, `demo`) dit quel chemin a fourni le texte ; la matrice réelle `scripts/capture-matrix.ps1` le lit dans la WebView2 (résultats dans `docs/UI-ISSUES.md`, UI-019). Avec la variable d’environnement `FLOWTRANSLATE_CAPTURE_TRACE`, l’avis « Rien à traduire » nomme l’étape de la copie synthétique qui a renoncé et l’âge de la dernière copie de l’utilisateur, jamais un texte.

Le remplacement (0.4.0) colle, comme Wispr Flow : la sélection existe encore dans l’application source, donc `capture::paste` (worker MTA, sous le verrou de session) revalide la cible (`validate_target` : même fenêtre au premier plan, réactivée par `SetForegroundWindow` seulement depuis le menu « Remplacer », même contrôle focalisé, même identifiant UIA quand UIA répond, même sélection quand elle était ancrée), attend le relâchement des modificateurs du raccourci (≤ 600 ms), sauvegarde le presse-papiers (`clipboard_guard::Keeper` : tous les formats sous verrou, ou le seul texte lu à la capture), y pose le résultat avec `ExcludeClipboardContentFromMonitorProcessing` et `CanIncludeInClipboardHistory = 0`, envoie **une** corde Ctrl+V par `SendInput` (scan codes, relâchement forcé si l’envoi est partiel), puis relit le champ en bonus pendant ≤ 800 ms (UIA `ValuePattern`/`TextPattern`, ou `WM_GETTEXT` sur `Edit`/`RichEdit`) : si le résultat s’y trouve, `Delivery { confirmed: true }` ; sinon, 300 ms après la corde, le collage est supposé fait (`confirmed: false`), jamais refusé pour cela. Seuls une cible changée, des modificateurs jamais relâchés, un presse-papiers indisponible ou un `SendInput` refusé donnent `fallback` : le verre s’ouvre avec le résultat et Copier. Le presse-papiers d’origine est remis en place tant que nous en sommes encore propriétaires : depuis la 0.6, la preuve est la propriété du presse-papiers, que seul un autre écrivain retire, et non plus un compteur de séquence (`clipboard_guard::restore_ours`) ; jamais par-dessus une copie plus récente, y compris après un échec. La cible est consommée dès la tentative : jamais deux collages pour un résultat. Le seul collage synthétique du produit est ce Ctrl+V dans la sélection d’origine, une fois par résultat ; jamais Ctrl+A, jamais Entrée, jamais de frappe du texte. `EM_REPLACESEL`, `complete_target` et la lecture du document entier ont disparu.

## Inférence et confidentialité

Les serveurs (1 à 8, depuis la 0.6 ; plus de profils Rapide/Qualité) acceptent HTTP et HTTPS pour tout hôte ; HTTP vers une autre machine est signalé « Connexion non chiffrée » dans l’interface (`settings::normalize_endpoint`, champ `insecure`). L’adresse est stockée sans `/v1` (suffixe retiré s’il est tapé) et l’app appelle `{base}/v1/…`. Les redirections HTTP sont désactivées. Le flux OpenAI SSE accepte les séparateurs LF et CRLF, les fragments UTF-8 et les événements répartis entre paquets. Seule une fin `finish_reason=stop` suivie de `[DONE]` produit l’événement `done`; une limite de longueur ou une fin prématurée produit une erreur. Depuis le lot 10 (Îlot), chaque erreur qui atteint le front porte un code (`error::ErrorKind` : statut HTTP, transport, flux, capture, collage) à côté du message français ; le corps de la réponse ne sert qu’à classer (un 404 qui parle du modèle) et n’en sort jamais (docs/BRIDGE.md). Une nouvelle requête annule la précédente et les événements périmés sont ignorés.

Le programme n’écrit dans les journaux ni source, ni traduction, ni presse-papiers, ni clé entière (le journal de diagnostic garde au plus ses 4 derniers caractères, `diagnostics::mask_key`). Il ne contient aucune commande shell ou ouverture d’URL arbitraire.

## Démonstration et essais manuels

`Overtype.exe --demo-selection` injecte une sélection ancrée et diffuse un résultat synthétique. `--demo-clipboard` injecte un repli presse-papiers. Ces options explicites ne modifient aucun serveur. `--demo` est un alias de la première.

`--simulate-inference` utilise la capture Windows réelle avec une réponse synthétique. Ces modes ne contactent aucun modèle et n’ajoutent pas d’historique. Ils sont indiqués dans l’infobulle de la zone de notification. Fermer l’instance existante avant de changer de mode.

Les fenêtres sont créées après l’initialisation de l’état Rust, puis le frontend installe ses listeners avant `frontend_ready`. Les dimensions logiques sont converties sur le moniteur source ; les déplacements Win32 utilisent `SWP_NOACTIVATE`. Un hook clavier traite Échap seulement quand une bulle est ouverte et que le premier plan est la source ou la bulle. Le contrôle de la sélection et de son ancre est périodique (environ 420 ms, 105 ms tant que le halo est visible), ce qui laisse un bref délai de détection ; le collage refait ses contrôles immédiatement avant la corde Ctrl+V. Après un collage sous l’Îlot (lot 9), UI Automation retrouve le texte collé juste avant le curseur (placement de la pilule, mots changés dans le halo, Annuler) ; le surveillant vérifie alors toutes les 105 ms que la fenêtre n’a ni bougé ni perdu le premier plan et que ce texte n’a pas défilé, et le crochet clavier retire Annuler dès qu’une vraie touche atteint la source (nos propres touches sont marquées dans `dwExtraInfo`). Annuler revalide fenêtre, contrôle, élément et texte après la réactivation, puis envoie Ctrl+Z ou recolle l’original.

Avant diffusion, vérifier sur Windows 11 à 100 %, 125 %, 150 % et 200 % : Word, Outlook Web, Teams Web et un champ natif; sélection simple et multiligne; sélection déplacée ou défilée pendant le flux; fenêtre source fermée; changement de presse-papiers; Escape; second raccourci; écran secondaire avec coordonnées négatives; résultat long; arrêt du serveur; réponse SSE tronquée. Confirmer que montrer et redimensionner n’activent pas l’overlay, que le côté choisi ne change pas pendant un flux et qu’aucun remplacement n’est possible après invalidation.

## Construction

Le frontend compilé doit exister dans `dist/`, puis exécuter depuis `src-tauri` :

```powershell
cargo test
cargo build --release
```

Le bundle NSIS est installé pour l’utilisateur courant. L’application ne démarre avec Windows que si l’option est activée.
